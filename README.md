
# Pankaj Tiwari — Ultra-Premium Portfolio

**Live Demo:** [https://pankajtiwari-art.github.io/My-Portfolio-/](https://pankajtiwari-art.github.io/My-Portfolio-/)

A cinematic, luxury personal brand website built with pure HTML, CSS, and JavaScript.  
Designed to feel like a futuristic, minimal, intelligent, and emotionally powerful.

---

## 🚀 Features

- Cinematic loading animation
- Custom animated cursor with glow effect
- Scroll‑triggered reveal animations
- Floating gradient orbs & particle grid background
- Glassmorphism cards with 3D tilt effect
- Typing text effect for dynamic roles
- Animated statistics counters
- Smooth scrolling & active navbar indicator
- Scroll progress bar
- Fully responsive (mobile, tablet, desktop)
- SEO‑friendly and accessible
- Deployable directly on **GitHub Pages**

---

## 🛠️ Tech Stack

- **HTML5** – semantic, accessible structure
- **CSS3** – custom properties, glassmorphism, keyframe animations, Grid/Flexbox
- **Vanilla JavaScript** – DOM manipulation, canvas particles, Intersection Observer, custom cursor, tilt effect

**Zero frameworks, zero external libraries.** Pure, production‑ready code.

## 📦 Getting Started

To run locally, simply clone the repository and open index.html in your browser:

git clone https://github.com/pankajtiwari-art/My-Portfolio-.git
cd My-Portfolio-
open index.html

No build tools or dependencies required.

---

## 🌐 Deployment

The site is automatically deployed via **GitHub Pages** from the main branch.  
Any push to the repository will update the live site.
